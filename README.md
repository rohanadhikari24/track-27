# Track 27

MBA application deadlines for the 2027 intake, drawn as a metro map. Every school is a line and every step is a station.

Open it: https://rohanadhikari24.github.io/track-27/

- `data.json` holds the dates and fees. A daily check updates it every morning (India time), reading each school's own site where it can.
- `index.html` is the page. It reads `data.json` each time it opens. Your own progress is saved in your browser only.

Always confirm dates and fees on the school's official site before you pay.
